# Tabuada

Teste de tabuada para crianças: 10 contas de multiplicação aleatórias (1 a 10), com som de comemoração quando acerta e som negativo quando erra.

No final mostra a nota:

- 9 ou 10: Parabéns!
- 7 ou 8: precisa melhorar um pouco mais
- abaixo de 7: precisa praticar mais

## Como usar

Abra o arquivo `index.html` em qualquer navegador (computador, tablet ou celular). Não precisa instalar nada nem de internet.
